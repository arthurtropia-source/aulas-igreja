# Identidade visual da Turma Especial (no plugin)

> Desde a 0.2.0 (12/11/2026), a Turma Especial é o curso padrão do plugin: esta pasta é lida pelo motor sempre que a pasta do curso não tem a própria `identidade/`. Origem: a pasta de identidade das aulas da TE, extraída em 20/10/2026 do deck final de Epístolas Paulinas II (o design aprovado pelo professor), e o design system oficial do folder TE 2027 (de 19/09/2026), trazido em 12/11/2026. Sem nenhuma foto.

| Arquivo | O quê |
|---|---|
| `identidade.md` | O nome do curso e os nomes dos arquivos abaixo (lido pelo motor) |
| `tema.css` | As cores e as famílias de fonte (variáveis CSS) |
| `fontes.css` e `fontes/` | As 20 fontes woff2. Cada peso tem dois arquivos, `-a` e `-b`: o navegador usa o `-b` e cai no `-a` para o caractere que faltar |
| `logo-preto.svg` · `logo-branco.svg` | O lockup horizontal, para fundo claro e para fundo vermelho ou preto |
| `LICENCAS.md` e `licencas/` | A origem e a licença de cada fonte (SIL OFL 1.1) e o uso do logo |
| `design-system/` | As regras oficiais da marca (`README-oficial.md`), os tokens, os logotipos e o selo de módulo. Ver `design-system/LEIA-ME.md` |

**Não se edita por pedido de aula.** Mudança de marca é versão nova do plugin, com a prova rodada.
