# Sugestões para o método

Quando um passo de uma skill faltar, sobrar ou atrapalhar, deixe um arquivo aqui: `AAAA-MM-DD-assunto.md`, com o que aconteceu, em que aula e o que teria ajudado. Quem cuida do plugin lê esta pasta e a sugestão vira versão nova. O que é gosto de um professor ou regra do curso não vem para cá: vai para `contexto/curso.md` ou `memoria.md`.
